# Wiki Changelog

Turn git history into a categorized, user-facing changelog.

**First load `deep-wiki:wiki-conventions`.** It defines repository resolution and commit-link formats.

## Inputs

| Argument | Meaning | Default |
|----------|---------|---------|
| A revision range (`v1.2.0..HEAD`, `abc123..def456`) | Commits to include | — |
| `--since <date>` (`2026-10-01`, `"4 weeks ago"`) | Start date | 30 days ago |
| `--write` | Also write `wiki/changelog.md` | Print only |

## Procedure

1. Collect commits: `git log <range> --no-merges --date=short --pretty=format:'%h%x09%ad%x09%an%x09%s'` (use `--since` when no range is given). Read bodies (`%b`) only for commits that look breaking or are ambiguous.
2. Group by period: one group per day for the last 7 days, then one per ISO week. For a tag range, use one group per tag.
3. Classify each commit. Conventional-commit prefixes win over keywords:

   | Emoji | Category | Signals |
   |-------|----------|---------|
   | ⚠️ | Breaking Changes | `!:` in the prefix, `BREAKING CHANGE:` in the body, `breaking`, `migrate`, `deprecate` |
   | 🆕 | New Features | `feat`, `add`, `new`, `implement`, `introduce` |
   | 🐛 | Bug Fixes | `fix`, `bug`, `patch`, `resolve`, `hotfix` |
   | 🔄 | Refactoring | `refactor`, `restructure`, `reorganize`, `clean` |
   | 📝 | Documentation | `docs`, `readme`, `comment` |
   | 🔧 | Configuration and CI | `config`, `ci`, `build`, `chore` |
   | 📦 | Dependencies | `deps`, `upgrade`, `bump`, `lock` |

4. Merge related commits into one user-facing line in the README's vocabulary. Link each line to its commit(s) using the conventions commit-link format.

## Output Format

```markdown
## 2026-11-20 — Faster event handling

One- or two-sentence summary of the period.

### ⚠️ Breaking Changes
- Description, with migration notes. ([abc1234](REPO_URL/commit/abc1234))

### 🆕 New Features
- Description. ([def5678](REPO_URL/commit/def5678))
```

Omit empty categories. Always list breaking changes first.

With `--write`, prepend frontmatter (`title: Changelog`, `description: Recent changes`) and write `wiki/changelog.md`, replacing the file only if it was generated by deep-wiki. Then tell the caller that `llms.txt` can now link it.
